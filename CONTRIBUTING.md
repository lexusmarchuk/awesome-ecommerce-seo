# Contribution Guidelines

Thanks for helping make **Awesome Ecommerce SEO** better! A few simple rules keep the list
high quality.

## What belongs here

- Tools and resources genuinely useful for **ecommerce / independent (DTC) store SEO** —
  Shopify, WooCommerce, BigCommerce, custom storefronts, etc.
- The tool must be **working, maintained, and reachable** (no dead links, no abandonware).

## How to add an entry

1. **Fork** this repository and edit `README.md` only.
2. Add your entry to the most relevant category, keeping the existing format:
   ```
   - [Tool Name](https://example.com/) - One clear sentence describing what it does.
   ```
   - Add the `` `free` `` tag right after the dash if the tool has a usable free tier or is fully free.
   - Keep the description to a single, factual sentence — no marketing fluff.
3. Keep entries within a category in a sensible order (free/essential tools first).
4. Make sure the tool **isn't already listed** and the **link works**.
5. Open a pull request with a descriptive title, e.g. `Add [Tool Name]`.

## Please don't

- Submit low-quality SaaS clones, link-shorteners, or affiliate-only redirects.
- Add your own tool more than once, or across multiple categories.
- Bundle many unrelated changes into one pull request — one tool per PR is easiest to review.

## Removing entries

If a tool shuts down, becomes paywalled beyond usefulness, or its link breaks, a PR to
remove or update it is just as welcome as an addition.
